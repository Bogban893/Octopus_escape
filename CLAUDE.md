# Octopus Escape

Кооперативная (1–2 игрока, по сети) стелс-игра на Unity 6000.6 + URP: осьминоги сбегают из лаборатории.

Автор — новичок в Unity и C#: объясняй решения, не только пиши код.

## Где что

- `ROADMAP.md` — этапы и прогресс (отмечать `[x]` по завершении задач).
- `docs/` — документация: дизайн, архитектура, сеть, соглашения, решения, системы. Начинай с `docs/README.md`.
- `Assets/Scripts/` — код. Структура и правила — `docs/ARCHITECTURE.md`, `docs/CONVENTIONS.md`.

## Правила

- Следовать `docs/ARCHITECTURE.md`: ввод отделён от логики, маленькие компоненты, интерфейсы, конфиги в ScriptableObject.
- Сетевой код по `docs/NETWORKING.md`: мир на сервере, движение у владельца, щупальца локально.
- Не перемещать и не переименовывать ассеты в обход Unity (`.meta`/GUID).
- Изменил поведение системы → обнови её документ в `docs/systems/`. Важное решение → `docs/DECISIONS.md`.

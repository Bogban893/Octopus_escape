# Сеть

## Стек

| Что | Пакет | Зачем |
|---|---|---|
| Сетевой движок | Netcode for GameObjects (`com.unity.netcode.gameobjects`) | синхронизация объектов, RPC |
| Игра через интернет | Multiplayer Services (`com.unity.services.multiplayer`) | Relay + Lobby: вход по коду без проброса портов |
| Тестирование | Multiplayer Play Mode (`com.unity.multiplayer.playmode`) | несколько игроков прямо в редакторе |

## Модель: хост + клиент

- Один игрок — **хост** (он же сервер), второй — **клиент**.
- **Одиночная игра = хост без клиентов.** Отдельного «оффлайн-режима» нет, поэтому код один.
- Выделенный сервер не нужен.

## Кто чем владеет (authority)

| Что | Кто решает | Почему |
|---|---|---|
| Движение своего осьминога | **Владелец** (owner authority) | Отзывчивое управление без задержки. Кооп — читерство не проблема |
| Щупальца (физика) | **Локально у каждого** | Это косметика. Синхронизировать 48 костей дорого и не нужно |
| За что держится осьминог | Владелец → все | Синхронизируется «намерение» (цель захвата), а щупальце дотягивается локально |
| Схваченный предмет | Тот, кто держит | Владение предметом передаётся хватающему |
| NPC, их восприятие и решения | **Сервер** | Один источник правды |
| Тревога, двери, цели, режим | **Сервер** | Один источник правды |
| UI, звук, VFX | Локально | Реагируют на синхронизированное состояние |

## Инструменты Netcode

- `NetworkObject` — объект, который существует у всех игроков.
- `NetworkBehaviour` — скрипт на таком объекте. `IsOwner`, `IsServer` подсказывают, где выполняется код.
- `NetworkVariable<T>` — **состояние** (уровень тревоги, открыта ли дверь). Автоматически доходит до всех, в том числе до тех, кто подключился позже.
- `Rpc` — **разовое действие** («я хочу открыть дверь», «проиграть звук»).
- `NetworkTransform` / `NetworkRigidbody` — синхронизация позиции.

Правило: **состояние → NetworkVariable, событие → RPC.**

## Типичный поток действия

Игрок-клиент открывает дверь:

```
Клиент: нажал E → InteractRpc(doorId)        (просьба серверу)
Сервер: проверил ключ-карту → isOpen.Value = true
Все:    isOpen.OnValueChanged → анимация двери
```

Клиент никогда не меняет мир сам — только просит сервер.

## Как тестировать

1. Window → Multiplayer → Multiplayer Play Mode → включить 2-го игрока.
2. Play: в одном окне Host, в другом Join.
3. Всегда проверяй фичу **со стороны клиента**, а не только хоста — большинство сетевых багов видно только у клиента.

## Открытые вопросы

- **Связанные осьминоги (этап 11):** каждый игрок владеет своим телом, но связь — общее физическое ограничение. Варианты: пружина к реплицированной позиции партнёра у каждого владельца; или передача авторитета над обоими телами хосту на таких уровнях. Решить через spike.
- **Схватить NPC (врач у сканера):** NPC серверный — нужен переход «NPC в руках игрока» без конфликта авторитета.

# Ассеты

## Модель осьминога

Файл: `Assets/Models/Octopus.fbx`. Исходник: `Art/Source/Octopus.blend` (Blender 5.2, хранится в LFS).

Размер в метрах: примерно 1.6 × 1.6 (в размахе щупалец), высота около 0.65.

### Экспорт из Blender

Экспортировать **только скриптом**, чтобы настройки всегда были одинаковыми:

```bash
blender -b Art/Source/Octopus.blend --python Tools/Blender/export_fbx.py -- Assets/Models/Octopus.fbx
```

Настройки импорта в Unity (уже выставлены в `.meta`):
- **Bake Axis Conversion: вкл.** Blender считает «верхом» ось Z, Unity — ось Y. Без этой галочки корень модели получает поворот −90°.
- **Convert Units: вкл.**, Scale Factor 1.

Типичная ошибка экспорта по умолчанию: корень с Rotation −90 и Scale 100. Если поставить такой меш отдельно в Mesh Filter, осьминог получится размером в сантиметры и будет лежать на боку.

### Скелет

```
Octopus
└── Root
    ├── Body
    ├── Head ── Head_end
    └── Arm1_1 → Arm1_2 → ... → Arm1_6 → Arm1_6_end
        ... (8 щупалец: Arm1 … Arm8, по 6 костей)
```

- 8 щупалец × 6 костей. Каждая кость — будущий сегмент физики (`Rigidbody` + `Joint`).
- `_end` — концевые кости. Удобны как точка «кончика» щупальца для хватания.

### Анимации

| Клип | Использование |
|---|---|
| `Idle` | стоит на месте |
| `Crawl` | движение |
| `Hide` | прячется (маскировка?) |
| `Peek` | выглядывает из укрытия |

Анимации будут управлять **телом и головой**. Щупальца ведёт физика (смешивание — этап 3).

### Материалы

`Octopus_skin`, `Octopus_belly`, `Octopus_eye`. Окрас для камуфляжа будем менять через параметры материала `Octopus_skin`.

## Правила импорта

- **Модели:** `.fbx`. Масштаб проверять по кубу 1×1×1 м. Rig: Generic (для осьминога; Humanoid — для людей-NPC).
- **Анимации:** для клипов, которые должны повторяться, включить `Loop Time`.
- **Материалы:** извлекать из FBX (Materials → Extract Materials) в `Assets/Materials`, чтобы их можно было редактировать.
- **Текстуры:** `.png`, размер — степень двойки (512, 1024, 2048).
- **Звук:** `.wav` для коротких эффектов, `.ogg` для музыки.

# Ассеты

## Модель осьминога

Файл: `Assets/Models/Octopus.fbx`.

### Скелет

```
Octopus
└── Root
    ├── Body
    ├── Head ── Head_end
    └── Arm1_1 → Arm1_2 → ... → Arm1_6 → Arm1_6_end
        ... (8 щупалец: Arm1 … Arm8, по 6 костей)
```

- 8 щупалец × 6 костей. Каждая кость — будущий сегмент физики (`Rigidbody` + `Joint`).
- `_end` — концевые кости. Удобны как точка «кончика» щупальца для хватания.

### Анимации

| Клип | Использование |
|---|---|
| `Idle` | стоит на месте |
| `Crawl` | движение |
| `Hide` | прячется (маскировка?) |
| `Peek` | выглядывает из укрытия |

Анимации будут управлять **телом и головой**. Щупальца ведёт физика (смешивание — этап 3).

### Материалы

`Octopus_skin`, `Octopus_belly`, `Octopus_eye`. Окрас для камуфляжа будем менять через параметры материала `Octopus_skin`.

## Правила импорта

- **Модели:** `.fbx`. Масштаб проверять по кубу 1×1×1 м. Rig: Generic (для осьминога; Humanoid — для людей-NPC).
- **Анимации:** для клипов, которые должны повторяться, включить `Loop Time`.
- **Материалы:** извлекать из FBX (Materials → Extract Materials) в `Assets/Materials`, чтобы их можно было редактировать.
- **Текстуры:** `.png`, размер — степень двойки (512, 1024, 2048).
- **Звук:** `.wav` для коротких эффектов, `.ogg` для музыки.

# Документация Octopus Escape

Здесь живёт всё, что нужно знать о проекте, чтобы работать с ним: что за игра, как устроен код, какие решения приняты и почему.

## Содержание

| Документ | О чём |
|---|---|
| [../ROADMAP.md](../ROADMAP.md) | Этапы реализации и прогресс |
| [GDD.md](GDD.md) | Дизайн игры: идея, механики, враги, режимы |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Архитектура кода, принципы, структура папок |
| [NETWORKING.md](NETWORKING.md) | Как устроен мультиплеер, кто чем владеет |
| [CONVENTIONS.md](CONVENTIONS.md) | Правила кода, именования, работы с Unity и git |
| [DECISIONS.md](DECISIONS.md) | Журнал принятых решений (и почему) |
| [ASSETS.md](ASSETS.md) | Модели, анимации, правила импорта |
| [systems/](systems/) | Документация по каждой игровой системе |

## Как поддерживать документацию

- **Начал новую систему** → скопируй [systems/_TEMPLATE.md](systems/_TEMPLATE.md) в `systems/<имя>.md`.
- **Принял важное решение** (выбрал подход, отказался от идеи) → запись в [DECISIONS.md](DECISIONS.md).
- **Закончил задачу** → отметь `[x]` в [ROADMAP.md](../ROADMAP.md).
- **Изменил поведение системы** → обнови её документ в том же коммите.

Документация, которая врёт, хуже отсутствующей. Короткая и правдивая — лучше длинной и устаревшей.

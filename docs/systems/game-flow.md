# Игровой цикл: режимы, тревога, цели

**Статус:** план
**Этап:** [ROADMAP](../../ROADMAP.md) — этапы 7–8
**Код:** `Assets/Scripts/Gameplay/Modes/`, `Alarm/`, `Objectives/`

## Назначение

Правила партии: как начинается, как выиграть или проиграть, как лаборатория реагирует на побег.

## Игровой режим

```
GameMode (абстрактный, серверный)
├── LabEscapeMode   — побег из лаборатории
└── BankHeistMode   — позже
```

Состояния режима: `Preparing → Playing → Ended(результат)`.
Режим решает, когда игра закончена и какая концовка. Остальные системы о концовках не знают.

`GameModeDefinition` (SO): название, сцена, правила (например, «связанные осьминоги»).

## Тревога

`AlarmSystem` — один на уровень, серверный.

| Уровень | Что происходит |
|---|---|
| Calm | обычный патруль |
| Suspicious | NPC внимательнее |
| Alert | закрываются железные двери, сирены |
| Lockdown | максимальная сложность |

Двери, свет, звук и NPC подписываются на `LevelChanged` сами. `AlarmSystem` не знает о них.

## Цели

`ObjectiveTracker` хранит прогресс: найдены ли нужные предметы, выполнены ли опциональные цели. `GameMode` использует его, чтобы решить исход и концовку.

## Сеть

Всё на сервере. Состояние передаётся через `NetworkVariable`, UI у клиентов реагирует на изменения.

# Взаимодействие и предметы

**Статус:** план
**Этап:** [ROADMAP](../../ROADMAP.md) — этапы 4–5
**Код:** `Assets/Scripts/Gameplay/Interaction/`

## Назначение

Всё, что осьминог может схватить, нажать или использовать. Плюс шум, на который реагируют NPC.

## Как работает

| Тип | Интерфейс / класс | Примеры |
|---|---|---|
| Можно схватить | `IGrabbable` | стакан, банка, ключ-карта |
| Можно активировать | `IInteractable` | дверь, кнопка, сканер |
| Описание предмета | `ItemDefinition` (SO) | id, имя, иконка, уровень доступа |
| Шум | `NoiseEvent` (позиция, громкость) | упавший стакан |

Предмет может реализовывать несколько интерфейсов сразу: ключ-карту можно схватить, и она открывает двери.

## Сеть

- Активация: клиент → `RequestInteractRpc` → сервер проверяет условия → меняет `NetworkVariable`.
- Шум рассылается только на сервере, потому что его слушают серверные NPC.

## Как расширять

**Новый предмет:** создать `ItemDefinition` в `Assets/Data/Items/`, сделать префаб с `NetworkObject` и `Grabbable`.
**Новый интерактивный объект:** класс-наследник `NetworkBehaviour` с реализацией `IInteractable`.

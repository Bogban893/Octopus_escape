# Game Design Document

Источник идей: [`octopus_escape.pdf`](octopus_escape.pdf) (доска со стикерами). Здесь — структурированная версия.

## Концепция

Кооперативный стелс-побег. Осьминоги — подопытные в лаборатории — пытаются сбежать.
Игра на **1–2 игроков по сети**. Каждый игрок управляет своим осьминогом.

Тон — смешной: физичные щупальца, нелепые ситуации, трусливые охранники.

## Управление

Управление **осьминогом целиком**, а не отдельными щупальцами — щупальца двигаются сами (процедурно/физически).

| Действие | Ввод |
|---|---|
| Движение | WASD |
| Камера | Мышь |
| Схватить / присосаться | ЛКМ |
| Отпустить / бросить | ПКМ |
| Сменить окрас | (TBD) |
| Взаимодействие | E (TBD) |

> Ранняя идея «колесиком выбирать активное щупальце» отложена — см. [DECISIONS.md](DECISIONS.md).

## Структура побега

1. **Скрытность** — нас не обнаружили, постепенно выбираемся по стелсу.
2. **После обнаружения** — бег и стелс, подлянки и ловушки (кинуть стакан, разлить клей, отвлечь).
3. **Концовки** (несколько):
   - вызов руководства (учёные пытаются скрыть побег);
   - замена осьминога манекеном в аквариуме или другим собратом (?).

## Карта

- На первое время — одна большая лаборатория.
- Несколько мест начального спавна.

## Способности осьминога

- Хватать и присасываться, бросать предметы.
- Ползать по стенам — только в специальных местах (потолок — нет).
- Менять окрас (маскировка), каждый игрок — своего осьминога.
- Расставлять манекены (назначение TBD).
- Позже: собрать робота-осьминожка на колёсиках из деталей — отвлекающий манёвр.

## Связанные осьминоги и запутывание

- На **некоторых** уровнях два осьминога связаны одним щупальцем.
- Запутывание щупалец — не постоянное, а периодическое на уровнях (запутались при беге, распутались в воде).

## Предметы и прогресс

- Для побега нужны предметы: ключ-карты охранников и т.п.
- Сканер лица: найти нужного врача, оглушить (?) и приложить его лицом к сканеру.
- Опциональные цели для сложности: пробирки (усиление), шмотки для маскировки.
- Химия: облить кислотой/реактивами → зомби-мутант под контролем на время.

## Противники

- Охранники и учёные пытаются поймать эксперимент.
- **Трусливый охранник** — кидается предметами, его можно оглушить.
- Способы поимки: ловушки, сети, транквилизаторы, просто банка.

## Тревога

Если учёные заметили осьминога вне клетки:
- NPC ищут внимательнее;
- многие пути закрываются железными дверями;
- вой сирен.

## Режимы

1. **Побег из лаборатории** — основной.
2. **Ограбление банка** — сильно позже. Механика хватания должна там отлично работать.

## Визуал

Low-poly, фиолетово-розовый осьминог. Референсы — в PDF (стр. 5): модель с разных ракурсов, концепт со стимпанк-элементами.
